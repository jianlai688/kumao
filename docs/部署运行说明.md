# 酷猫音乐平台 · 部署运行说明

## 一、环境要求

| 组件      | 版本   | 说明                 |
| ------- | ---- | ------------------ |
| JDK     | 17+  | Spring Boot 3.x 要求 |
| Maven   | 3.8+ | 构建                 |
| Node.js | 18+  | 前端构建               |
| Docker  | 20+  | 中间件一键部署（可选）        |

## 二、启动中间件

```bash
cd docker
docker compose up -d
```

> MinIO 镜像：默认使用 `pgsty/minio:RELEASE.2026-08-04T00-00-00Z`（MinIO 官方镜像在 Docker Hub 已下架，国内拉取常失败）。若需官方版，可改为 `minio/minio:RELEASE.2024-06-13T22-53-53Z` 并配合加速站拉取。

启动后各组件地址：

| 组件            | 地址                                       | 账号                      |
| ------------- | ---------------------------------------- | ----------------------- |
| MySQL         | 127.0.0.1:3306                           | root / kumao123456      |
| Redis         | 127.0.0.1:6379                           | 无密码                     |
| Nacos         | <http://127.0.0.1:8848/nacos>            | nacos/nacos（默认关闭鉴权）     |
| RabbitMQ      | <http://127.0.0.1:15672>                 | guest / guest           |
| MinIO 控制台     | <http://127.0.0.1:9001>                  | minioadmin / minioadmin |
| Elasticsearch | <http://127.0.0.1:9200>                  | 无                       |
| Sentinel 控制台  | <http://127.0.0.1:8858>                  | sentinel/sentinel       |
| SRS 推流        | rtmp://127.0.0.1:1935/live               | -                       |
| SRS HLS 拉流    | <http://127.0.0.1:8088/live/room_1.m3u8> | -                       |

> 直播控制台点击「开始直播」后，若 SRS 上还没有主播推流，live-service 会自动调用 ffmpeg 生成演示推流。请保证 `ffmpeg` 在 PATH 中，或通过 `LIVE_AUTOPUSH_FFMPEG` 指定路径；使用 `LIVE_AUTOPUSH_ENABLED=false` 可关闭自动推流。

> MySQL 首次启动会自动执行 `sql/` 目录下的脚本建库建表并写入演示数据。

若已有 MySQL，可手动执行：

```bash
mysql -uroot -p < sql/01-schema.sql
mysql -uroot -p < sql/02-data.sql
mysql -uroot -p < sql/03-passwords.sql
# 其余增量脚本 04~20 按编号顺序执行，其中 13-ai-model-config.sql 为 AI 模型配置，14-ai-auto-review.sql 为自动审核任务，15-moderation.sql 为禁言字段，16-content-moderation-queue.sql 为评论/弹幕 AI 审核与人工复核队列，17-id-card-verification.sql 为主播/音乐人/广告商身份证正反面认证字段，18-home-setting.sql 为首页展示设置，19-ad-slot-price.sql 为广告位价格，20-anchor-payout.sql 为主播收款账户字段
```

## 三、编译后端

```bash
mvn -DskipTests clean package
```

产物位于各模块 `target/*.jar`。

## 四、启动服务（按依赖顺序）

建议启动顺序：gateway 可最后启动，其余服务无强依赖。

```bash
java -jar user-service/target/user-service.jar
java -jar music-service/target/music-service.jar
java -jar playlist-service/target/playlist-service.jar
java -jar comment-service/target/comment-service.jar
java -jar file-service/target/file-service.jar
java -jar live-service/target/live-service.jar
java -jar search-service/target/search-service.jar
java -jar vip-service/target/vip-service.jar
java -jar musician-service/target/musician-service.jar
java -jar ad-service/target/ad-service.jar
java -jar review-service/target/review-service.jar
java -jar kumao-gateway/target/kumao-gateway.jar
```

或使用脚本：`bash scripts/start-all.sh`（Linux/Mac）/ `scripts/start-all.bat`（Windows）。

环境变量可覆盖默认配置：

```
NACOS_ADDR / MYSQL_HOST / MYSQL_PORT / MYSQL_USER / MYSQL_PASSWORD
REDIS_HOST / REDIS_PORT / REDIS_PASSWORD
MINIO_ENDPOINT / MINIO_ACCESS_KEY / MINIO_SECRET_KEY
RABBITMQ_HOST / ES_URIS / JWT_SECRET
```

支付相关环境变量（支付宝沙箱 / 微信支付）见 `docs/支付接入说明.md`。

## 五、启动前端

```bash
cd kumao-web
npm install
npm run dev
```

访问 <http://localhost:5173>

Vite 已配置代理：`/api` → `http://127.0.0.1:8080`，`/ws` → `ws://127.0.0.1:8080`。

## 七、关键链路验证

1. **登录鉴权**：`POST /api/auth/login` 获取 token，后续请求带 `Authorization: Bearer {token}`
2. **榜单缓存**：`GET /api/music/rank/hot` 二次访问命中 Redis
3. **MV 高清鉴权**：`GET /api/music/mv/4002/play` —— 普通用户 403，VIP 用户可播
4. **播放记录异步**：`POST /api/comment/play-records` → RabbitMQ → `play_record` 表
5. **弹幕**：WebSocket `ws://localhost:8080/ws/live?roomId=11001&token=xxx`；AI 通过自动广播，未通过转管理员复核
6. **评论**：`POST /api/comment/comments`；AI 通过自动展示，未通过进入待复核队列，管理员在「AI审核工作台」或评论管理页处理
7. **检索**：`GET /api/search/search?keyword=周杰伦`，ES 不可用时自动降级 MySQL
8. **限流**：网关 Sentinel 全局 200 QPS/IP，超限返回 `{"code":429,"message":"访问过于频繁，请稍后再试"}`
9. **AI 审核**：管理员通过 `/api/admin/ai/status` 查看模型/本地规则状态，`POST /api/admin/ai/review` 获取审核建议，`/api/admin/ai/auto/status` 查看自动审核调度；未配置模型时应返回 `source=LOCAL_RULE`，仍按本地规则自动放行或转人工。

完整回归脚本为 `tests/e2e-api-test.ps1`，覆盖网关、11 个业务服务（含 `review-service:8111`）及 AI 审核链路。Windows 启动脚本会保留外部传入的 `MYSQL_PORT` 等环境变量，使用 Docker override 时可直接设置 `MYSQL_PORT=3307`。
