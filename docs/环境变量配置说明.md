# 环境变量与密钥配置说明

> 自本次整改起，`application.yml` 中**不再内置任何真实凭据**。凡是密码、密钥类配置一律写成
> `${VAR}` 形式，缺省值时服务启动会直接报 `Could not resolve placeholder`，从而避免"默认值悄悄上线"。

## 1. 变量清单

| 变量 | 作用 | 本地开发取值 | 生产要求 |
|---|---|---|---|
| `MYSQL_PASSWORD` | MySQL 密码 | `kumao123456`（本机容器） | 必须覆盖为强密码 |
| `RABBITMQ_USER` / `RABBITMQ_PASSWORD` | RabbitMQ 账号 | `guest` / `guest` | 必须覆盖 |
| `MINIO_ACCESS_KEY` / `MINIO_SECRET_KEY` | MinIO 账号 | `minioadmin` / `minioadmin` | 必须覆盖 |
| `JWT_SECRET` | 网关与各服务共用的 JWT 签名密钥 | `kumao-local-dev-jwt-secret-change-me` | **必须**覆盖为 32 字节以上随机串 |
| `AI_CONFIG_SECRET` | review-service 加密存储模型配置 | `kumao-local-dev-ai-config-secret` | **必须**覆盖 |
| `SRS_PUSH_KEY` | 直播推流鉴权 | `kumao-srs-push-key` | 建议覆盖 |
| `ALIPAY_PRIVATE_KEY` | 支付宝应用私钥（PKCS8，无 BEGIN/END 头） | 从 `scripts\local-env.bat` 读取 | 放到密钥管理/环境变量，不入库 |
| `ALIPAY_PUBLIC_KEY` | 支付宝公钥（回调验签） | 同上 | 可入库（公钥非敏感） |
| `WECHAT_*` | 微信支付商户参数 | 留空即自动降级为模拟支付 | 按需覆盖 |

其余变量（`MYSQL_HOST`、`REDIS_HOST`、`ES_URIS`、`SRS_RTMP_HOST` 等）仍是地址类配置，保留本地默认值，不影响安全。

## 2. 本地开发

```bat
copy scripts\local-env.example.bat scripts\local-env.bat
REM 编辑 scripts\local-env.bat，填入支付宝私钥等真实值
scripts\start-all.bat
```

- `scripts\local-env.bat` 已被 `.gitignore` 忽略，**不会被提交**。
- `start-all.bat` 会自动 `call` 该文件；文件不存在时使用脚本内的本地开发默认值，仍可一键启动。
- Linux/macOS 同理，复制 `scripts/local-env.example.sh` 为 `scripts/local-env.sh`。

## 3. 公网部署（deploy\start-public.bat）

- 优先读取环境变量，其次 `scripts\local-env.bat`。
- `JWT_SECRET` 未设置时，脚本调用 `scripts\ensure-secret.ps1` 首次生成随机密钥并持久化到
  `.secrets\jwt-secret.txt`（已被 `.gitignore` 忽略），**重启不会导致用户掉线**。
- 若要更换密钥，删除该文件后重启即可（已签发 token 全部失效）。

## 4. 安全事件记录：支付宝应用私钥泄露

初始提交 `22be523` 起，`vip-service/src/main/resources/application.yml` 中的
`ALIPAY_PRIVATE_KEY` 默认值是一段完整的 RSA 应用私钥，随公开仓库对外暴露。现已从前述文件移除，
但**历史提交中仍存在**。处置建议：

1. 登录支付宝开放平台，对沙箱/正式应用**重置应用私钥**（生成新密钥对，上传新公钥）；
2. 把新私钥写入本机 `scripts\local-env.bat`，不要写回 `application.yml`；
3. 如需从 Git 历史中彻底抹除，需重写历史后强推（会改变所有历史 commit 的 SHA）：

   ```bash
   pip install git-filter-repo
   git filter-repo --replace-text replacements.txt   # 文件中写入该私钥 → **REMOVED**
   git push --force --all origin
   ```

   注意：仓库已公开，密钥可能已被抓取，**重写历史不能替代吊销重签**。
