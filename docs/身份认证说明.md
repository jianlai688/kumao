# 主播 / 音乐人 / 广告商实名认证

## 认证要求

主播、音乐人、广告商三类入驻认证都必须提交：

- 真实姓名；
- 身份证号；
- 身份证人像面照片；
- 身份证国徽面照片。

身份证照片通过统一文件上传接口上传，返回图片地址后随申请资料一起提交。只提交姓名或证件号、没有上传正反面照片的申请不能提交；管理员也不能通过资料不完整的申请。

## 申请接口字段

`POST /api/users/anchor/apply`、`POST /api/musician/musician/apply`、`POST /api/ad/ad/apply` 均支持并强制要求：

```json
{
  "realName": "张三",
  "idCard": "110101199001011234",
  "idCardFrontUrl": "/static/kumao/id-card/2026/11/12/xxxx.jpg",
  "idCardBackUrl": "/static/kumao/id-card/2026/11/12/yyyy.jpg"
}
```

其余字段按各业务原有申请接口填写。

## 图片上传

```http
POST /api/file/files/upload?bizType=id-card
Content-Type: multipart/form-data
Authorization: Bearer {token}

file=<图片文件>
```

支持 JPG / PNG / WebP / GIF，单张不超过 10MB。返回 `data.url` 即为证件照片地址。

## 管理员审核

- 主播审核页、音乐人审核页、广告商审核页会显示身份证号及正反面缩略图，点击可预览大图。
- AI 审核工作台的主播资质、音乐人资质、广告制作人资质队列也会展示证件缩略图。
- 证件照片缺失时，后端审核接口拒绝通过，AI 本地规则也会将该申请标为待复核。

## 隐私

- 音乐人公开主页和公开列表已屏蔽身份证号、正反面照片字段，仅本人和管理端可见。
- 主播申请、广告商申请接口只返回给本人或管理员，不进入公开接口。
- 审核模型只接收“证件号/正反面是否已提交”的布尔标记，不把完整证件号或图片地址发送给外部模型。

## 数据库

执行：

```bash
mysql -h127.0.0.1 -P3307 -uroot -pkumao123456 kumao_music < sql/17-id-card-verification.sql
```

脚本为 `anchor_apply`、`musician`、`advertiser` 增加 `id_card_front_url`、`id_card_back_url` 字段，并为音乐人/广告商增加 `id_card` 字段，可重复执行。
