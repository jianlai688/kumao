# 主播直播控制台与复盘

## 页面

| 路由 | 页面 | 说明 |
|---|---|---|
| `/studio/live/:id` | 直播控制台 | 主播实时画面、数据概览、播放队列、弹幕/礼物/榜单/歌单互动 |
| `/studio/report/:sessionId` | 本场复盘 | 单场 KPI、在线曲线、礼物分布、观众画像与结算状态 |
| `/studio/earnings` | 礼物收益 | 礼物收益汇总、明细筛选、分页与提现入口 |

## 控制台

- 直播中卡片显示红色 LIVE 徽标与每秒自增的已播时长。
- 在线、观看、点赞、礼物、新增粉丝数值变化时会做 300ms 数字滚动。
- 画面预览为 16:9 本地预览层，封面模糊背景加 48 段音频波形；右下角标注「本地预览 · 未推流」。
- 右侧互动栏固定 380px，包含弹幕、礼物、榜单、歌单四个 Tab。
- 结束直播会弹出自绘确认层，确认后生成 sessionId 并把报告写入浏览器本地 `km_live_reports_v1`，随后跳转本场复盘。

## 本场复盘

- 报告优先读取控制台结束时写入本地存储的本场数据；直接访问不存在的 sessionId 时使用内置演示数据。
- 在线曲线为原生 SVG `<polyline>`，带网格、hover 十字线和读数。
- 「导出报告」下载 JSON 文件；「再来一场」跳转 `/studio/live/:id/prepare`，该路由会回到主播工作台并复用原直播间配置打开发布弹窗。

## 礼物收益

- 数据来源：`GET /api/live/live/gifts/received`，按当前主播过滤；直播间名称来自 `GET /api/live/live/rooms/mine`。
- 今日/本月/累计与可提现余额由礼物记录实时计算；今日之后的记录按待结算展示，昨日及更早按已结算展示。
- 提现按钮仅做绑定引导，跳转「主播资料」完成支付宝/微信收款账户绑定。
