# 户外直播使用说明

主播在创建直播间时可以选择 **室内直播 / 户外直播**，户外直播会额外记录直播地点，并为主播生成手机扫码推流二维码。

## 一、主播操作

1. 进入「创作者中心 → 主播工作台 → 创建直播间」。
2. 直播场景选择 **户外直播**，填写直播地点（如「西湖断桥 · 湖边步道」）。
3. 创建后点击 **推流地址**：
   - 页面会展示推流二维码和 RTMP 推流地址；
   - 用手机推流 App（支持自定义 RTMP 的 App）扫码，或手动粘贴推流地址；
   - 确认摄像头、麦克风权限后开始推流；
   - 回到工作台点击 **直播画面** 先确认推流画面和声音正常，再在预览弹窗中点击 **开始直播**。
4. 直播中，工作台卡片封面会显示主播端实时画面；点击封面或「直播画面」可放大预览，方便确认构图、灯光，并可在播放器中开启声音检查收音。
5. 观众在「音乐直播」广场可按 **户外直播** 场景筛选，直播间卡片和详情页会显示「📍 地点」标识。

## 二、推流地址与网络

- 推流地址格式：`rtmp://{SRS_PUSH_HOST}:1935/live/room_{roomId}?token=...`
- 不配置 `SRS_PUSH_HOST` 时，后端会自动选择本机默认路由的局域网 IP（避免选中 VMware/WSL/热点等虚拟网卡）。
- 手机与服务器需网络互通：
  - 同一 Wi-Fi：使用电脑局域网 IP 即可；
  - 公网/4G 推流：把 `SRS_PUSH_HOST` 配置为公网 IP 或域名，并在防火墙/安全组放行 `1935/tcp`。
- 如果自动识别的 IP 不正确，在 `live-service` 启动环境变量中显式指定：
  ```text
  SRS_PUSH_HOST=192.168.1.100
  ```

## 三、相关字段与接口

- `live_room.scene`：`INDOOR` / `OUTDOOR`
- `live_room.location`：户外直播地点
- `GET /api/live/live/rooms/square?scene=OUTDOOR`：按场景筛选
- `GET /api/live/live/rooms/scenes`：场景字典
- `GET /api/live/live/rooms/{id}/push-url`：户外场景额外返回 `pushQr`（base64 二维码）与 `tip`

## 四、数据库升级

已有数据库执行一次：

```bash
docker exec -i kumao-mysql mysql -uroot -pkumao123456 --default-character-set=utf8mb4 < sql/05-live-outdoor.sql
```

## 五、播放失败排查

页面显示「直播信号中断」时，按以下顺序检查：

1. **确认 SRS 收到推流**  
   访问 `http://127.0.0.1:1985/api/v1/streams`，`streams` 为空说明主播还没有推流，页面没有画面是正常现象。
2. **确认推流地址**  
   主播工作台 → 直播间 → 推流地址，使用 OBS「自定义 RTMP」：
   - 服务器：`rtmp://127.0.0.1:1935/live`
   - 串流密钥：`room_{roomId}?token=...`（以页面显示的完整推流地址为准）
3. **确认 HLS 地址**  
   推流成功后访问 `http://127.0.0.1:8088/live/room_{roomId}.m3u8`，应返回播放列表而不是 404。
4. **确认播放器支持**  
   Web 端已通过 `hls.js` 播放 HLS，Chrome/Edge 不需要额外插件；Safari 使用原生 HLS。若使用 HTTPS 页面访问 HTTP 的 SRS 地址，会出现混合内容拦截，需要给 SRS 配置 HTTPS 或通过同源反向代理。
5. **远程观看**  
   `pullUrl` 默认是 `http://127.0.0.1:8088`，仅本机可访问。其他设备观看时请将 `SRS_PLAY_HOST` 配置为服务器局域网/公网地址，例如：
   ```text
   SRS_PLAY_HOST=http://192.168.1.100:8088
   ```
   并重启 live-service；前端也会在页面通过非 localhost 地址打开时自动把 `127.0.0.1` 替换为当前页面主机名。

## 六、实时播放链路

播放器优先使用 **HTTP-FLV**（`http://<SRS>:8088/live/room_{id}.flv`），延迟通常为 1~3 秒；FLV 不可用时自动降级到 HLS（`room_{id}.m3u8`）。

直播间 WebSocket（`/ws/live?roomId=&token=`）除弹幕外还会下发 `STREAM_STATUS` 消息：

- `content=ONLINE`：主播开始推流，页面自动接入 FLV/HLS；
- `content=OFFLINE`：推流结束，页面自动显示信号中断。

状态由 live-service 轮询 SRS HTTP API（默认每 3 秒）后广播，避免依赖 Docker 内到宿主机的 HTTP 回调；可调整：

```text
SRS_API_URL=http://127.0.0.1:1985
SRS_STATUS_INTERVAL_MS=3000
```
